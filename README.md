# Home Automation Resources

A collection of Home Assistant projects, blueprints, and related device configuration profiles.

## Projects

### [Light - Daylight Brightness Boost](projects/daylight-brightness-boost/README.md)

A Home Assistant automation blueprint for Inovelli dimmers integrated through Zigbee2MQTT, with matching device profile examples and configuration notes.

## Organization

Resources are grouped by project so each project keeps its blueprint, supporting profiles, and project-specific documentation together. Shared resources can be introduced at the repository level if and when multiple projects need them.
